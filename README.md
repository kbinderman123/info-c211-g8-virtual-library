# Virtual Library

Proposed INFO-C211 Programming 2 team project for G8, Fall 2026.

## Purpose

A small Java desktop application for maintaining a book catalog. Users will be
able to add books, search by title or author, and check books out and back in.
The initial version will use an in-memory collection and a simple Swing window;
it will not require a server, external service, or database.

## Proposed structure

- `Book`: title, author, catalog identifier, and checkout status.
- `Library`: collection management, searching, checkout, and return operations.
- `LibraryWindow`: Swing interface and application entry point.

An array or linked list will store the catalog, as required by the course.
The final delivery will include source code, an executable JAR, usage instructions,
and screenshots.
